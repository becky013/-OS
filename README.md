# Pet Life Operating System

An interactive, high-fidelity iPhone prototype for pet care, reconstructed from the Pet Life Figma Make demo.

## Live demo

https://becky013.github.io/-OS/

## Local preview

```bash
npm install
npm run dev
```

## GitHub Pages

The static GitHub Pages version is stored in `docs/`. The workflow in
`.github/workflows/deploy-pages.yml` publishes it automatically after changes
are pushed to the `main` branch.

To rebuild the static version locally:

```bash
npm run build:pages
```
